## Building a Personal Knowledge Base

In this step, I'm going to write a personal profile document ,build a python script that loads,chunks,and stores my profile as embeddings.Embeddings are numerical vectors which are generated by converting unstructred data into long arrays of numbers.These nymbers capture the semantic meaning of the content.If two sentences mean similiar things,their vector coordinated will be close to each other in a high-dimensional space.

![Image](https://nextwork.ai/mischievous_red_festive_forbidden_fruit/uploads/99ec4595-3d7b-5584-a799-aafb9c373bbb_g3h7m2r5)

### Creating the profile document

I included information about my goals,career aspirations in my profile.This will help AI to answer the specific personal questions with help of RAG!

### How semantic search finds relevant chunks

When I ask a question, ChromaDB finds the chunks whose vectors are closet in that high-dimensional space.This is sematic search in action.Instead of amtching the exact keywords,it finds the content with closest,meaning.

## Creating the RAG API with FastAPI

In this step, I'm going to build an API that will automatically retrieve context, augment the prompt, and generate a grounded answer. I'll test it using built in Swagger UI.

![Image](https://nextwork.ai/mischievous_red_festive_forbidden_fruit/uploads/99ec4595-3d7b-5584-a799-aafb9c373bbb_j5m1r8t2)

### How the /ask endpoint works

When a question comes it retrieves the 2 most relevant chunks from ChromaDB, augments the prompt by combining those chunks with the question, and generates a grounded answer using qwen2.5:0.5b. The response includes the context that was used so you can verify the AI's sources.

### Testing with Swagger UI

I tested my API by asking "what is my name?".The AI answered with "Your name is Hrushika".The context used was the profile.txt file ,the document from which RAG extracted the information.

In this project extension, I added a POST endpoint that accepts an optional user parameter. Metadata filtering allows to search through a particulat user's chunks.Without it ,all profiles are searched.
